# Wild Files (`wild-files`)

Animal superlatives with honest scale comparisons and a GBIF-derived range map instead of a stock clip.

Numbering: feed #6 → next #7 (`series/series.json` is the counter; `tools/new_episode.py wild-files …` bumps it).

## Format rules
- Stage: `compare` (silhouettes to scale, PhyloPic CC0) · `bars` · `geo` range map (GBIF hex-binned occurrences, DOI cited)
- Photos only CC0/CC BY with a visible `screen_credit`; IUCN status quoted, never their maps
- Engine status: `compare` + GBIF range layer are Phase-2

## Sources
See `docs/DATA_SOURCES.md` (Wild Files section). Every fact → `research.json` claim; every file → `media.json`.
